Question and audience

Question: How effectively do a starting pitcher’s workload (pitch count) and metrics (walks and strikeouts), after controlling for average velocity and spin rate, predict the number of runs allowed per start in September of 2025?

Intended Audience: Major League Baseball (MLB) front-office, pitching coaches, and player development staff.

Why the Answer Matters: Understanding the connection between pitch count, walks/strikeouts, and velocity/spin rate allows teams to optimize pitch counts, identify the exact threshold where performance degrades, and make more informed, data-driven decisions regarding in-game bullpen management.

Response Variable (Y): Runs allowed per starting appearance. Important Predictors (X):Pitch Count: Measures cumulative workload and fatigue. Walks (BB): Measures control and defensive lapses. Strikeouts (SO): Measures swing-and-miss dominance. Average Velocity: Captures physical power. Average Spin Rate: Captures pitch movement and deception.

Data

Working Source / Citation: Data is retrieved programmatically from MLB Advanced Media (Baseball Savant) using the baseballr R package (Petti & Gilani).

Permission & Ethics: The data is publicly available for research and educational purposes. Because it records professional athletes’ public on-field performance metrics, there are no private citizen privacy issues, consent restrictions, or ethical concerns.

Observational Unit: A single starting pitcher appearance (one starting assignment for an individual pitcher in a single regular-season MLB game).Dimensions: The filtered and aggregated dataset contains approximately \(300\) to \(500\) rows (representing starting pitcher outings over a concise sample window, such as a two-week window) across \(6\) columns containing the response and candidate predictors.

Response Variable (Y): Total runs allowed (runs_allowed) by the starting pitcher during their outing.Candidate Predictors (X):Pitch Count (pitch_count): Total pitches thrown in the appearance (workload/fatigue proxy). Walks (walks): Total walks surrendered (command/control metric). Strikeouts (strikeouts): Total strikeouts recorded (dominance metric). Average Velocity (avg_velocity): Mean velocity of pitches thrown during the outing (raw power metric).Average Spin Rate (avg_spin_rate): Mean spin rate of pitches thrown during the outing (movement/deception metric).

Collection Process: Captured automatically across all major league ballparks via advanced optical and radar tracking hardware, then compiled into game logs by MLB Advanced Media.

Evidence It Can Answer the Question: The dataset directly records both physical output variables and workload/result metrics on a consistent per-start observational scale, providing the exact empirical variance required to evaluate how fatigue and command influence run prevention.

# 1. Pull Statcast data with player_type = "pitcher" so player_name is the PITCHER
statcast_raw <- scrape_statcast_savant(
  start_date = "2025-09-01", 
  end_date = "2025-09-30",
  player_type = "pitcher" # <-- This is the critical fix!
)

# 2. Aggregate by unique game and pitcher to get full-game starting appearances
starting_pitcher_data <- statcast_raw %>%
  group_by(game_pk, game_date, pitcher, player_name) %>%
  summarise(
    pitch_count = n(),
    strikeouts = sum(events == "strikeout", na.rm = TRUE),
    walks = sum(events == "walk", na.rm = TRUE),
    avg_velocity = mean(release_speed, na.rm = TRUE),
    avg_spin_rate = mean(release_spin_rate, na.rm = TRUE),
    runs_allowed = max(post_home_score, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  filter(pitch_count >= 30) # Filters out relievers and keeps true starting workloads

The pitch count coefficient (\(\hat{\beta}_1 = -0.019\)) indicates that each additional pitch decreases expected runs allowed by 0.019, with a 95% confidence interval from -0.033 to -0.005 (\(p = 0.007\)). This counterintuitive negative association is driven by managerial selection bias (pulling struggling pitchers early), highlighting the opportunity to control for pitch quality and command in a multiple regression model.

Where the analysis could go

  1. Multiple Linear Regression with Polynomial and Interaction Terms

We will add quadratic pitch count terms (\(\text{pitch\_count}^2\)) and interaction terms between workload and physical pitch characteristics (\(\text{pitch\_count} \times \text{avg\_velocity}\)). This approach models non-linear performance degradation and reveals whether pitch count fatigue impacts runs allowed more heavily when velocity or spin rate begins to decline.

  1. Regularized Regression (LASSO / Ridge / Elastic Net)

We will fit penalized regression models across all candidate metrics including pitch counts, command stats, velocity, and spin rates.This method prevents overfitting and addresses multicollinearity among pitch quality metrics, allowing front offices to isolate the most essential predictors of run prevention.
